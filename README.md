# こつこつ日和

日々の「できた」を記録すると、相棒の犬が育っていくスマホ向けの習慣記録・ダイエット応援アプリです。

## 起動

ビルドや依存パッケージのインストールは不要です。Python 3 があれば、リポジトリ直下で次を実行します。

```sh
python3 -m http.server 4317 --bind 127.0.0.1 --directory dist
```

ブラウザで http://127.0.0.1:4317 を開いてください。

## 機能

- 運動・食事・ストレッチ・休息の記録
- 習慣の累計による犬の成長となつき度の増加
- 記録の間隔に応じた表情や、「なでる」への反応
- 朝・昼・午後・夕方・夜に合わせた、こむぎからの短い声かけ
- 画面いっぱいのおへや、床のタップで移動、「おいで」で呼び寄せ
- 画面下のメニューから記録・もようがえ・履歴を開き、記録後はこむぎのおへやへ戻る
- おへやの飾り付け、気分・体重の記録、JSONバックアップ

データはブラウザの localStorage（`kotokoto-wellness-v1`）に保存されます。端末・ブラウザ間の自動同期はありません。

## ファイル

- `dist/index.html`: 画面
- `dist/style.css`: レイアウト、ポメラニアンの表示・アニメーション
- `dist/room-ui.css`: 全画面のおへや、コンパクトな操作メニューと記録パネル
- `dist/assets/room-portrait-v2.jpg` / `room-landscape-v2.jpg`: 縦・横画面用の手描き風の部屋背景
- `dist/assets/komugi-pomeranian-v1.png`: 3段階 × 4表情の透過画像
- `dist/assets/komugi-pomeranian-walk-v1.png`: 3段階 × 4コマの歩行画像
- `dist/companion-motion.mjs`: おさんぽ・呼び寄せ・一時停止・表示範囲の制御
- `dist/companion-chat.mjs`: 時間帯に合わせた声かけ・頻度・表示中断・おしゃべり設定
- `dist/app.mjs`: 画面の操作と保存
- `dist/model.mjs`: 記録・成長・なつき度の処理
- `.openai/hosting.json`: 既存Sitesの公開設定
- `AGENTS.md`: 開発の引き継ぎ

既存の公開先: https://kotokoto-biyori.loyal-wave-1919.chatgpt.site

## こむぎの見た目

ユーザーが選んだ、クリーム色と淡いアプリコット色のポメラニアンです。子犬・育ちざかり・おとなの3段階と、普段・うれしい・寂しい・なでられたときの4表情を透過画像で表示します。記録の累計や日付に応じて画像を切り替え、「なでる」や記録時には寄ってくる動きを付けています。

`design/` に承認された試作と、組み込みの画像生成ツールで使用したプロンプトを保存しています。画像の行は成長順、列は普段・うれしい・寂しい・なでられたときの順です。

おへやでは、歩く・立ち止まる・座るを繰り返します。床をタップするとその場所まで歩き、「おいで」や記録・「なでる」で手前へ近づきます。非表示のタブでは停止し、端末で動きを減らす設定をしている場合は自動のおさんぽを止めます。移動位置や一時停止は一時的な表示状態で、保存データの形式は変更していません。

部屋を引きで眺める全画面UIです。スマホでは縦長、横長の画面では横長の背景に切り替えます。初期表示は `#room`。画面下のメニューから `#today`・`#decorate`・`#records`、こむぎの名前や吹き出しから `#companion` を開きます。スマホの操作パネルは下から、横幅900px以上では右側に表示します。

背景は家具の輪郭や質感をデフォルメした、やわらかい手描きのイラスト風です。配置・日差し・広い床は初版から引き継ぎ、実写寄りの初版画像も比較用に残しています。生成プロンプトは `design/illustrated-room-backgrounds-v2.prompt.txt` に保存しています。

## こむぎのおしゃべり

部屋を開いて約12秒後、その後は4〜7分おきに、時間帯に合った言葉を16秒ほど表示します。たとえば朝は「おはよう。今日はどんな日にしようか？」、夕方は「今日もがんばった？」。端末の時刻を使い、今日の記録や気分に合うひとことも混ざります。

記録や「なでる」の反応を優先し、入力パネルや設定画面を開いている間、タブが非表示の間は話しかけません。設定の「ときどき話しかける」で休められます。音や、アプリを閉じたときの通知はありません。

おしゃべりの設定と直近の声かけ時刻は、記録とは別の `kotokoto-companion-chat-v1` に保存します。記録の形式・バックアップ内容は変更していません。検証は `node --test test/companion-chat.test.mjs` で実行できます。
